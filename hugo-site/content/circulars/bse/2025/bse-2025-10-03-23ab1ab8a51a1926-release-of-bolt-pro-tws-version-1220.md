## Summary

BSE has released BOLT Pro TWS Version 12.20, which introduces a new classification and capture mechanism for Location IDs. Traders must now configure separate Location IDs for Manual Orders, Batch Orders, and Basket Orders.

## Key Points

- Release of BOLT Pro TWS Version 12.20.
- Separate Location ID configuration required for Manual Orders (Mandatory), Batch Orders (Optional), and Basket Orders (Optional).
- System prevents order placement from Batch or Basket windows if Location IDs are not explicitly configured when required.
- Updating Location IDs can be done via Preferences -> Settings -> Change within the terminal.

## Regulatory Changes

- Enhancement in registering dealer terminals as per previous circular numbers 20250924-54 and 20250925-4.

## Compliance Requirements

- Trading members must upgrade to BOLT Pro TWS version 12.20 and ensure respective Location IDs are appropriately mapped in the terminal settings to prevent trading interruptions.

## Important Dates

- Effective with the release of BOLT Pro TWS version 12.20 (Circular dated October 3, 2025).

## Impact Assessment

- Operational impact on trading desks using BOLT Pro TWS who must update their terminal settings and configure separate Location IDs for specialized order windows.
