## Summary

BSE has issued a circular regarding enhancements in registering dealer terminals and updating the identification structure for location IDs. The revisions incorporate identification for ALGO orders originating from client Direct APIs and outline specific 14th-digit validations across various trading platforms.

## Key Points

- Revised location ID structure to accommodate client Direct API algo orders.
- Defined explicit 14th-digit values for modes of trading across ETI, IBT, STWT, DMA, and Client Direct API.
- Mapped specific 13-digit prefixes to their corresponding algorithmic and non-algorithmic descriptions.

## Regulatory Changes

- Updated rule definitions for the first 16 digits and specific 14th-digit validations of location IDs as defined in earlier exchange notices.
- Introduction of validation codes specifically for client Direct API and algorithmic execution paths.

## Compliance Requirements

- Trading members must ensure their order routing systems and location ID configurations comply with the updated 14th-digit validation rules for algorithmic and non-algorithmic orders.

## Important Dates

- Effective immediately as per exchange notification standards.

## Impact Assessment

- Operational impact for trading members and API users who must update their location ID formatting and validation logic to align with the revised exchange standards.
