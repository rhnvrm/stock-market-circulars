## Summary

This circular outlines the updated and correct requirements for FATCA/CRS information, specifically detailing the revised Taxpayer Identification Number (TIN) ID type master codes and descriptions.

## Key Points

- Revised TIN ID type master includes various categories such as Student Visa, Diplomat Visa, Global Entity Identification Number, US GIIN, and more.
- Standardized codes are established for accurate reporting and compliance under FATCA/CRS guidelines.

## Regulatory Changes

- Introduction of a revised ID type master with updated codes (e.g., Code J for Student Visa, Code K for Diplomat Visa, Code N for Global Entity Identification Number, Code Q for US GIIN, etc.).

## Compliance Requirements

- Entities and market participants must ensure that FATCA/CRS submissions adhere to the revised TIN ID type master codes.

## Important Dates

- Effective immediately for compliance reporting.

## Impact Assessment

- Enhances data accuracy and regulatory reporting standards for foreign account tax compliance and common reporting standard requirements.
