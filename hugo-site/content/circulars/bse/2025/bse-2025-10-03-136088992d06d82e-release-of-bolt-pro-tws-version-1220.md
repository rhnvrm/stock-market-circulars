## Summary

BSE has announced the release of BOLT Pro TWS Version 12.20. The updated version introduces a new classification of Location IDs for manual, batch, and basket orders in compliance with previous exchange circulars concerning the enhancement of registered dealer terminals.

## Key Points

- Introduction of BOLT Pro TWS Version 12.20.
- Separate Location ID configuration required for Manual Orders (Mandatory), Batch Orders (Optional), and Basket Orders (Optional).
- System prompts for Location IDs during login based on order types.
- Error messages will be displayed if Location IDs are not configured for specific functionalities like Batch or Basket order windows.

## Regulatory Changes

- Enhancement in registering dealer terminals requiring separate Location IDs for different order placement windows as per circular numbers 20250924-54 and 20250925-4.

## Compliance Requirements

- Trading members must upgrade to BOLT Pro TWS Version 12.20 and configure the required Location IDs via the preferences and settings window to prevent order placement restrictions.

## Important Dates

- Effective with the release of version 12.20 (Circular dated October 3, 2025).

## Impact Assessment

- Operational workflow change for traders using BOLT Pro TWS who must now configure distinct Location IDs for manual, batch, and basket orders during login and through terminal settings.
