## Summary

This circular provides guidelines on the comprehensive scope and testing methodology for Vulnerability Assessment and Penetration Testing (VAPT) for the financial year. It outlines the specific IT environments, systems, and testing frameworks that regulated entities must incorporate into their security evaluations.

## Key Points

- The VAPT scope must be transparent to SEBI and Exchanges, covering all critical assets and infrastructure.
- Included assets: Networking systems, security devices, servers, databases, storage systems, applications, cloud deployments, and public-facing endpoints.
- Specific testing areas include internal/external infrastructure VA, application VA, external penetration testing, Wi-Fi testing, API security, network segmentation, cloud implementations, mobile applications, OS/DB assessment, and configuration audits.
- Testing methodology must be thoroughly documented with records and evidence, drawing from frameworks such as SEBI CSCRF, NCIIPC, CERT-In, NIST SP 800-115, ISO 27001, PCI-DSS, OSSTMM, and OWASP.

## Regulatory Changes

- Detailed mandatory coverage of cloud deployments, APIs, mobile applications, and configuration audits for operating systems, databases, and middleware.

## Compliance Requirements

- Regulated entities must ensure their VAPT scope comprehensively covers all listed infrastructure and application components.
- Documentation of testing methodologies and evidence must be maintained and made available for review.

## Important Dates

- Applicable for FY 2025-26 compliance timelines.

## Impact Assessment

- Enhances the cybersecurity posture of market participants through standardized and rigorous penetration testing requirements.
