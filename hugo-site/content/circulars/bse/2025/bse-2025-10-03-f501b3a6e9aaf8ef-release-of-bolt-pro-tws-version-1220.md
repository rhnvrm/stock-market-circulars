## Summary

BSE has announced the release of BOLT Pro TWS Version 12.20. This update incorporates enhancements to capture Location IDs separately for Manual Orders, Basket Orders, and Batch Orders in compliance with previous exchange circulars regarding dealer terminal registrations.

## Key Points

- Introduction of separate Location ID configuration fields during login and within preferences.
- Manual Order Location ID is mandatory for login and order placement.
- Batch Order Location ID and Basket Order Location ID are optional configuration fields.
- System prevents order placement and prompts error messages if Location IDs are not configured for basket or batch windows.

## Regulatory Changes

- Implementation of enhanced terminal registration tracking as mandated by circulars dated 24th September 2025 and 25th September 2025.
- Segregation of Location IDs across different order types for better audit trails and order routing.

## Compliance Requirements

- Trading members must upgrade to BOLT Pro TWS Version 12.20.
- Traders must configure respective Location IDs under Preferences > Settings to execute basket and batch orders seamlessly.

## Important Dates

- Release Date: 3rd October 2025 (Reference ID: 20251003-8)

## Impact Assessment

- Operational workflow changes for traders using batch and basket order windows, requiring upfront configuration of Location IDs to avoid order placement restrictions.
