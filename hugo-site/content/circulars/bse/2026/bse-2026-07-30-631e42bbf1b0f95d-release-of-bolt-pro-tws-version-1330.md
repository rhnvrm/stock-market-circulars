## Summary

BSE has announced the compulsory release of BOLT Pro TWS Version 13.30, scheduled to go live on Monday, August 3, 2026. The new version introduces changes related to the introduction of the Closing Auction Session across Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR segments.

## Key Points

- Compulsory version release: BOLT Pro TWS Version 13.30.
- Effective date: August 3, 2026.
- Applicable segments: Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR segments.
- Key functionality: Changes related to the introduction of the Closing Auction Session.
- Availability: Downloadable from July 31, 2026, 7:00 PM onwards; available for testing during the mock trading session on August 1, 2026.

## Regulatory Changes

- Introduction of Closing Auction Session mechanics integrated into the trading workstation software effective from August 3, 2026.

## Compliance Requirements

- All trading members using leased line connections must upgrade to BOLT Pro TWS version 13.30 before the effective date.
- Users can upgrade via the Auto-Download Interface or download the update package from the BSE website and follow the installation instructions.

## Important Dates

- Download start date: July 31, 2026 (from 7:00 PM)
- Mock trading / testing date: August 1, 2026
- Effective date: August 3, 2026

## Impact Assessment

- High operational impact for all trading members across multiple segments, requiring timely software upgrades to ensure uninterrupted trading and compatibility with the new Closing Auction Session.
