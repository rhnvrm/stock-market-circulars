## Summary

BSE has issued an update regarding the revision of the go-live date for rolling out new versions of Market Data APIs in the Currency Derivatives segment, extending the implementation timeline to October 2026.

## Key Points

- Revised go-live date for NFCAST API (Version 6.2) and MDI / EMDI API (Version 1.4.5) is October 12, 2026.
- Mock trading for the new API versions is scheduled for October 10, 2026.
- EOBI API Version 1.4 remains unchanged with no modifications.
- Changes will be available in the Test Environment starting from September 10, 2026.

## Regulatory Changes

- Extension and rescheduling of the rollout timeline for market data application programming interfaces in the currency derivatives segment.

## Compliance Requirements

- Trading members and front-end trading application vendors must complete necessary testing in their respective applications within the test environment to ensure a smooth rollout.

## Important Dates

- Test Environment Availability: September 10, 2026
- Mock Trading: October 10, 2026
- Revised Go-Live Date: October 12, 2026

## Impact Assessment

- Operational impact is moderate, affecting trading members and software vendors who integrate with BSE's currency derivatives market data feeds, requiring them to update and test their systems against the new API versions.
