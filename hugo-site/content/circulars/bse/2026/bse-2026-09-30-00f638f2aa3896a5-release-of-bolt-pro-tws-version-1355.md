## Summary

BSE has announced the release of BOLT Pro TWS version 13.55, which will go live on October 1, 2026. This version update is optional and applies to trading members operating across Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR segments.

## Key Points

- **Version:** BOLT Pro TWS Version 13.55
- **Effective Date:** October 01, 2026
- **Applicability:** Optional upgrade for Equity, Equity Derivatives, Currency Derivatives, Commodity Derivatives, and EGR segments.
- **Download Availability:** Available from September 30, 2026, 7:00 PM onwards via Auto-Download Interface or the exchange website.

## Regulatory Changes

No regulatory or policy changes; this is a software version release containing technical enhancements.

## Compliance Requirements

Trading members using Leased Line Connections or other supported setups may optionally upgrade to version 13.55 by downloading and installing the update via the Auto-Download Interface or BSE website help section.

## Important Dates

- **Download Start Date:** September 30, 2026 (from 7:00 PM onwards)
- **Live Date:** October 01, 2026

## Impact Assessment

Minimal operational impact as the version upgrade is optional and focused on technical enhancements for trading terminals.
