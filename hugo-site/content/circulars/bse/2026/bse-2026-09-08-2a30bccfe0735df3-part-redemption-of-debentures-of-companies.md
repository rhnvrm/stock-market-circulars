## Summary

BSE has informed trading members that several companies have fixed record dates for the purpose of payment of interest and part redemption of Non-Convertible Debentures (NCDs). Trading in these debentures will take place with a reduced face value effective from the respective record/ex-dates in September 2026.

## Key Points

- **Suruchi Properties Private Limited**: Scrip Code 976775, ISIN INE217T07027, Record/Ex-Date: 10/09/2026, Reduced Face Value: Rs. 69,630/- per debenture.
- **Parampujya Solar Energy Private Limited**: Scrip Code 973761, ISIN INE127V07024, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 1,26,758/- per debenture.
- **Vertis Infrastructure Trust**: Scrip Code 974227, ISIN INE0KXY07026, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 9,35,000/- per debenture.
- **IndiGrid Infrastructure Trust**: Scrip Code 974781 (ISIN INE219X07371) with reduced face value Rs. 87,000/- and Scrip Code 975036 (ISIN INE219X07389) with reduced face value Rs. 82,140/- per debenture; Record/Ex-Date: 15/09/2026.
- **Northern Arc Capital Ltd.**: Scrip Code 975570, ISIN INE850M07467, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 16,666.67 per debenture.
- **Mizuho Capsave Finance Private Limited**: Scrip Code 976286, ISIN INE0DBJ07192, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 41,662/- per debenture.
- **IKF Finance Limited**: Scrip Code 976301, ISIN INE859C07212, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 41,666.69 per debenture.
- **Aptus Finance India Private Limited**: Scrip Code 976302, ISIN INE04MH07034, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 56,250/- per debenture.
- **Akara Capital Advisors Private Limited**: Scrip Code 976306, ISIN INE08XP07274, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 15,000/- per debenture.
- **Cube Highways Trust**: Scrip Code 976397, ISIN INE0NR607033, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 98,250/- per debenture.
- **Lendingkart Finance Limited**: Scrip Code 976450, ISIN INE090W07725, Record/Ex-Date: 15/09/2026, Reduced Face Value: Rs. 17,000/- per debenture.

## Regulatory Changes

None.

## Compliance Requirements

Trading members must note the reduced face values and record dates for trading and settlement of the specified debentures.

## Important Dates

- **10/09/2026**: Record Date and Ex-Date for Suruchi Properties Private Limited.
- **15/09/2026**: Record Date and Ex-Date for Parampujya Solar Energy, Vertis Infrastructure Trust, IndiGrid Infrastructure Trust, Northern Arc Capital, Mizuho Capsave Finance, IKF Finance, Aptus Finance India, Akara Capital Advisors, Cube Highways Trust, and Lendingkart Finance Limited.

## Impact Assessment

Trading in the affected non-convertible debentures will proceed with the updated reduced face values following the specified record dates.
