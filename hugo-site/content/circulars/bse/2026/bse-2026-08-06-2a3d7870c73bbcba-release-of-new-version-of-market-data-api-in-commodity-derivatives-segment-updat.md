## Summary

BSE has announced a revision in the go-live and mock trading dates for rolling out the new version of Market Data APIs in the Commodity Derivatives segment, following previous circular number 20260625-31.

## Key Points

- Revised go-live date for NFCAST API (Version 6.2) and MDI / EMDI API (Version 1.4.5) is October 12, 2026.
- Mock trading for the new APIs is rescheduled to October 10, 2026.
- EOBI API (Version 1.4) remains unchanged with no modifications.
- Changes will be accessible in the Test Environment starting September 10, 2026.

## Regulatory Changes

- Extension of timeline for upgrading market data streaming APIs in the Commodity Derivatives segment.

## Compliance Requirements

- Trading members and front-end application vendors must complete testing in the test environment prior to the live rollout.

## Important Dates

- Test Environment Availability: September 10, 2026
- Mock Trading Date: October 10, 2026
- Revised Go-Live Date: October 12, 2026

## Impact Assessment

- Gives market participants additional time to integrate and test the updated market data APIs (NFCAST and MDI/EMDI) before the production rollout.
