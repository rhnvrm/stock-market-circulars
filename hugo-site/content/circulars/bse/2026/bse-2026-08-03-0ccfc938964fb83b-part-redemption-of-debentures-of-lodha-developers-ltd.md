## Summary

BSE has issued a notice informing trading members about the actual reduced face value of non-convertible debentures (NCDs) of Lodha Developers Ltd following part-redemption, effective from August 4, 2026.

## Key Points

- **Company Name:** Lodha Developers Ltd
- **Scrip Code 976923 (INE670K07307):** Reduced face value is Rs. 77,379/- per debenture.
- **Scrip Code 977293 (INE670K07349):** Reduced face value is Rs. 54,343/- per debenture.
- **Effective Date:** August 4, 2026 (DR-686/2026-2027).

## Regulatory Changes

None.

## Compliance Requirements

Trading members must take note of the reduced face value for trading purposes.

## Important Dates

- **Effective Date:** August 4, 2026

## Impact Assessment

Operational update for trading members concerning debenture valuation and settlement.
