## Summary

BSE has announced the release of a new version of the NFCAST market data API (version 6.3) for the Equity Segment. This release facilitates upcoming changes regarding the review of certain aspects of the Closing Auction Session, market timings, and settlement methodology for derivatives contracts in the Equity Segment, effective December 07, 2026.

## Key Points

- Release of NFCAST market data API version 6.3 incorporating necessary technical changes for equity segment market operations.
- Issued with reference to SEBI circular dated October 15, 2026, and Exchange circular no. 20261016-14 dated October 16, 2026.
- API documentation and updates are made available on the BSE website (http://www.bseindia.com/nta.aspx).
- Trading members and front-end trading application vendors are required to update and test their applications in the simulation environment.

## Regulatory Changes

- Integration of technical parameters supporting the review of the Closing Auction Session, market timings, and settlement methodology in the Equity Segment.

## Compliance Requirements

- Trading members and front-end trading application vendors must initiate necessary code changes in their respective applications.
- Members are required to test updated applications in the test (simulation) environment notified by the Exchange.

## Important Dates

- Notice Date: October 19, 2026
- Effective Date of Underlying Changes: December 07, 2026

## Impact Assessment

- Moderate operational impact on trading members and software vendors relying on BSE market data feeds (NFCAST), requiring timely API integration and testing ahead of the December 2026 rollout.
