## Summary

BSE has issued a notice detailing Standardization Testing and Quality Certification (STQC) and other compliance requirements for software vendors as per SEBI's Cyber Security and Cyber Resilience Framework (CSCRF). All software services and COTS products provided by empanelled and prospective vendors must undergo application security testing and functional audits by STQC.

## Key Points

- SEBI circular reference: SEBI/HO/ITD-1/ITD_CSC_EXT/P/CIR/2024/113 dated August 20, 2024.
- Covers all software services including SaaS, hosted services, COTS, customized COTS, and in-house developed software.
- Mandates Application Security Testing (DAST and SAST) and Functional Audits through STQC auditors.
- Provisional empanelment can be granted based on STQC acknowledgement of testing completion.
- Compensatory Control Letters signed by the CTO are required if vulnerabilities are pending closure upon report submission.

## Regulatory Changes

Enforcement of mandatory STQC application security and functional audit certification for empanelled and prospective software vendors providing trading, IBT, STWT, API, and back-office solutions under the SEBI CSCRF framework.

## Compliance Requirements

- Perform Dynamic Application Security Testing (DAST) against vulnerabilities like OWASP Top 10 and SANS Top 25 CWE.
- Perform Static Application Security Testing (SAST) on source code.
- Conduct Functional Audits covering login/authentication, user management, input validation, navigation, CRUD operations, and business logic validation.
- Submit STQC certification and complete registration processes as prescribed by the Exchange.

## Important Dates

- Notice Date: 03 Sep 2026

## Impact Assessment

Software vendors and COTS providers must align their development and testing lifecycles with STQC requirements and obtain necessary certifications to maintain or secure empanelment with stock exchanges and depositories.
