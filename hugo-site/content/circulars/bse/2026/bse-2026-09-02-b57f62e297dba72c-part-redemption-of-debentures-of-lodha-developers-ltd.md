## Summary

BSE has issued a notice informing trading members about the part redemption of debentures and the consequent revision in face value for Lodha Developers Ltd, effective from September 3, 2026.

## Key Points

- Company Name: Lodha Developers Ltd
- Scrip Code 976923 (INE670K07307, LDL-Reset Rate-21-01-28-PVT): Reduced face value is Rs. 75,703/- per debenture.
- Scrip Code 977293 (INE670K07349, LDL-TBILLS-13-11-28-PVT): Reduced face value is Rs. 53,124/- per debenture.
- Effective Date: September 03, 2026.
