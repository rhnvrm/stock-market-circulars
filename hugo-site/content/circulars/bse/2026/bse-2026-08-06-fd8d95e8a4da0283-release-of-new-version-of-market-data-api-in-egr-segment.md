## Summary

BSE has issued a notice regarding the revision of the go-live date and mock trading schedule for rolling out new versions of Market Data APIs in the Electronic Gold Receipt (EGR) segment.

## Key Points

- Revised go-live date for NFCAST API (Version 6.2) and MDI / EMDI API (Version 1.4.5) is October 12, 2026.
- Mock trading for the new versions is scheduled for October 10, 2026.
- Changes will be available in the test environment starting September 10, 2026.
- EOBI API (Version 1.4) remains unchanged.

## Regulatory Changes

- Extension and rescheduling of the rollout timeline for EGR market data streaming protocols.

## Compliance Requirements

- Trading members and front-end trading application vendors must complete necessary testing in the test environment to ensure a smooth rollout.

## Important Dates

- Test Environment Availability: September 10, 2026
- Mock Trading Date: October 10, 2026
- Revised Go-Live Date: October 12, 2026

## Impact Assessment

- Provides market participants additional time to integrate and test the upgraded API versions for market data feeds in the EGR segment.
