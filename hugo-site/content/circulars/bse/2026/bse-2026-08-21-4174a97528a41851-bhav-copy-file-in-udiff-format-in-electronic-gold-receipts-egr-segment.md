## Summary

BSE has announced the introduction of the Bhav Copy file in Unified Distilled File Format (UDiFF) for the Electronic Gold Receipts (EGR) segment. The new format goes live on August 24, 2026, with a parallel run of the existing format until September 25, 2026.

## Key Points

- Introduction of UDiFF format for the EGR segment Bhav Copy file.
- Parallel availability of the legacy format (EGR_BHAVCOPY_DDMMYY) until September 25, 2026.
- Files will be available for download on the BSE website and Extranet after trading hours.

## Regulatory Changes

- Standardization of market data distribution formats using UDiFF for the EGR segment.

## Compliance Requirements

- Trading members must update their internal systems and ingestion pipelines to support the new UDiFF format prior to the discontinuation of the legacy format.

## Important Dates

- **Live Date:** August 24, 2026
- **Parallel Run End Date:** September 25, 2026

## Impact Assessment

- Minimal impact on trading operations, requiring only backend data pipeline adjustments for members consuming EGR Bhav Copy files.
