## Summary

BSE has released a new ETI API version (ver. 1.6.15) for Equity, Equity Derivatives, Currency Derivatives, and Commodity Derivatives segments. The update covers order cancellation scenarios due to Matching Engine reinitialization during trading hours.

## Key Points

- New ETI API version 1.6.15 is now available on the Exchange website.
- Includes updates on order cancellation scenarios from Matching Engine reinitialization.
- No structural changes in the new API version.

## Regulatory Changes

N/A

## Compliance Requirements

Trading members are advised to review and ensure that their trading applications correctly process and handle cancellation events in accordance with reconciliation procedures.

## Important Dates

- Notice Date: September 22, 2026

## Impact Assessment

Minimal operational impact as there are no structural API changes, but trading members should verify their order cancellation handling logic.
