## Summary

BSE has issued an update regarding the revision to the FATCA/UBO file structure and validations on the BSE StAR MF Platform. Based on communications from Registrars and Transfer Agents (RTAs), the proposed file structure remains under evaluation, and current validations will continue to apply.

## Key Points

- Proposed FATCA/UBO file structure is under evaluation by RTAs.
- Existing FATCA/UBO file structures and validations remain applicable until further notice.
- Continues from Exchange Notice No. 20260717-32 dated July 17, 2026.

## Regulatory Changes

No immediate changes; current file formats and validation rules remain in effect.

## Compliance Requirements

Members should continue using the current FATCA/UBO file formats on the BSE StAR MF Platform without changes.

## Important Dates

- Notice Date: 30 Jul 2026
- Effective: Immediate continuation until further notice

## Impact Assessment

Minimal operational impact as existing workflows remain unchanged.
