## Summary

BSE has informed trading members that Kolte-Patil Developers Ltd has fixed a record date for the part redemption of its non-convertible debentures (NCDs). Trading in the company's debentures will take place with a reduced face value effective from the record date.

## Key Points

- Company Name: Kolte-Patil Developers Ltd
- Purpose: Part Redemption of Non-Convertible Debentures
- Record Date: 31/07/2026
- Ex-Date: 31/07/2026
- Affected ISINs and Details:
  - Scrip Code 974771 (INE094I07049): Reduced Face Value Rs. 46343/- per Debenture
  - Scrip Code 976030 (INE094I07072): Reduced Face Value Rs. 38655/- per Debenture
  - Scrip Code 977231 (INE094I07080): Reduced Face Value Rs. 90520/- per Debenture
  - Scrip Code 977351 (INE094I07098): Reduced Face Value Rs. 89560/- per Debenture

## Regulatory Changes

None.

## Compliance Requirements

Trading members must take note of the reduced face values and ensure trading and settlement are conducted accordingly.

## Important Dates

- Record Date: 31 July 2026
- Ex-Date: 31 July 2026

## Impact Assessment

Investors holding the specified NCDs of Kolte-Patil Developers Ltd will receive part redemption payments, and subsequent trading will reflect the updated reduced face values.
