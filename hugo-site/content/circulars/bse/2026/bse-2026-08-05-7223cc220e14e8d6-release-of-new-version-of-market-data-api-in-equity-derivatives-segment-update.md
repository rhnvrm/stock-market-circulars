## Summary

BSE has issued a partial modification regarding the release of the new version of Market Data APIs in the Equity Derivatives segment. The go-live date for the MDI/EMDI API (Version 1.4.5) is revised to August 24, 2026, while the schedule for NFCAST Version 6.2 remains unchanged.

## Key Points

- Revised go-live date for MDI/EMDI API (Version 1.4.5) is August 24, 2026.
- NFCAST API Version 6.2 go-live remains September 07, 2026.
- EOBI Version 1.4 remains unchanged with no new version.
- Changes facilitate the rollout of pre-open session modifications and the dissemination of closing reference prices for stock futures between 3:15 pm and 3:20 pm.

## Regulatory Changes

- Extension and alignment of go-live dates for market data stream upgrades in the Equity Derivatives segment following previous circulars.

## Compliance Requirements

- Trading members and front-end trading application vendors must complete necessary testing in their respective applications in the simulation environment to ensure a smooth rollout.

## Important Dates

- August 24, 2026: Go-live date for MDI/EMDI API Version 1.4.5 (Mock Trading on August 22, 2026).
- September 07, 2026: Go-live date for NFCAST API Version 6.2 (Mock Trading on September 05, 2026).

## Impact Assessment

- Operational impact is moderate, requiring technical teams and vendors to ensure API integrations and testing are completed prior to the revised go-live deadlines.
