## Summary

BSE has issued an update regarding the release of new versions of Market Data APIs in the Equity Derivatives segment, revising the go-live date for the MDI/EMDI API (Version 1.4.5) to August 31, 2026.

## Key Points

- Revised go-live date for MDI / EMDI API (Version 1.4.5) is August 31, 2026 (Mock trading scheduled for August 29, 2026).
- No change in the go-live date for NFCAST Version 6.2, which remains September 07, 2026 (Mock trading on September 05, 2026).
- No change for EOBI (Version 1.4).
- APIs facilitate pre-open session modifications and dissemination of closing reference price for stock futures between 3:15 pm – 3:20 pm.

## Regulatory Changes

- Partial modification to previous Exchange circulars nos. 20260805-32 and 20260803-36 concerning timeline revisions for market data API versions in the Equity Derivatives segment.

## Compliance Requirements

- Trading members and front-end trading application vendors must complete necessary testing in the test environment to ensure smooth rollout.

## Important Dates

- Mock Trading (MDI / EMDI API Version 1.4.5): August 29, 2026
- Go-Live Date (MDI / EMDI API Version 1.4.5): August 31, 2026
- Mock Trading (NFCAST API Version 6.2): September 05, 2026
- Go-Live Date (NFCAST API Version 6.2): September 07, 2026

## Impact Assessment

- Operational adjustments required for trading members and vendors to align with the revised go-live schedule for market data streams.
