## Summary

BSE announced the upgrade of its trading platform to strengthen market infrastructure, accelerate innovation, and enhance efficiency. As part of this initiative, the Exchange is releasing Enhanced Transaction Interface (ETI) API version 13.0 and Enhanced Order Book Interface (EOBI) API version 3.0, incorporating updated specifications, functional enhancements, and recovery frameworks.

## Key Points

- **ETI API ver. 13.0:** Introduces decimal quantity support in the Quantity field for greater precision and flexibility, along with aligned interface structures.
- **EOBI API ver. 3.0:** Features decimal quantity support, Auction Best Bid/Offer (BBO) and Top-of-Book messages, Mass Instrument State Change messages, Gateway-In Timestamp (RequestTime), and an enhanced recovery/resiliency framework.
- **Member Readiness:** Trading members, ISVs, algo vendors, and data vendors are encouraged to review updated specifications, change logs, and adapt market data processing, order book construction, and feed parser implementations.
- **Simulation Testing:** ETI API v13.0 and EOBI API v3.0 will be available in simulation from October 2026 (Currency Derivatives in October 2026, Equity Derivatives in November 2026).

## Regulatory Changes

Platform-level technical upgrade and release of new API specifications replacing or updating previous interface versions.

## Compliance Requirements

Trading members and technology vendors must review the ETI API ver. 13.0 and EOBI API ver. 3.0 Change Log, update internal applications, and participate in simulation testing and certification.

## Important Dates

- **Simulation Environment Availability:** October 2026 onwards (Currency Derivatives: October 2026; Equity Derivatives: November 2026).

## Impact Assessment

High operational impact for trading members, algo vendors, and software vendors requiring system changes for compatibility, enhanced latency analysis, and platform readiness.
