## Summary

The Bombay Stock Exchange (BSE) has issued a notice informing trading members that several companies have fixed record dates for the payment of interest and part redemption of Non-Convertible Debentures (NCDs). Trading in the debentures of these companies will take place with a reduced face value effective from the respective dates.

## Key Points

- **SRG Housing Finance Limited**: Scrip Code 977242 (ISIN: INE559N07066), Record Date & Ex-Date: 09/09/2026, Reduced Face Value: Rs. 83,333.33 per debenture.
- **India Shelter Finance Corporation Limited**: Scrip Code 976546 (ISIN: INE922K07104), Record Date & Ex-Date: 11/09/2026, Reduced Face Value: Rs. 62,500/- per debenture.
- **SRG Housing Finance Limited**: Scrip Code 977076 (ISIN: INE559N07058), Record Date: 14/09/2026, Ex-Date: 11/09/2026, Reduced Face Value: Rs. 80,303.03 per debenture.
- **Adani Green Energy (UP) Limited**: Scrip Code 973750 (ISIN: INE155V07025), Record Date & Ex-Date: 15/09/2026, Reduced Face Value: Rs. 126,758/- per debenture.
- **Prayatna Developers Private Limited**: Scrip Code 973756 (ISIN: INE925U07023), Record Date & Ex-Date: 15/09/2026, Reduced Face Value: Rs. 126,758/- per debenture.

## Regulatory Changes

None. Standard corporate action notification.

## Compliance Requirements

Trading members must take note of the reduced face values and record/ex-dates for settlement purposes.

## Important Dates

- **09/09/2026**: Record Date and Ex-Date for SRG Housing Finance (Scrip Code 977242)
- **11/09/2026**: Record Date, Ex-Date for India Shelter Finance (Scrip Code 976546) and Ex-Date for SRG Housing Finance (Scrip Code 977076)
- **14/09/2026**: Record Date for SRG Housing Finance (Scrip Code 977076)
- **15/09/2026**: Record Date and Ex-Date for Adani Green Energy (UP) Limited and Prayatna Developers Private Limited

## Impact Assessment

Ensures transparency and accurate valuation for secondary market trading of debentures undergoing part redemption.
