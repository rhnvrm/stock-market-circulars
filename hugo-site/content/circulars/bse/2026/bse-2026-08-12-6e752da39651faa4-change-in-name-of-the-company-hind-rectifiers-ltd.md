## Summary

Hind Rectifiers Ltd has informed the Bombay Stock Exchange (BSE) regarding a change in its company name to **Hirect Limited**. The name change on the BOLT Plus System will take effect from **August 18, 2026**. Notably, there will be no change to the Scrip Code or the Scrip ID of the company.

## Key Points

- **Existing Name:** Hind Rectifiers Ltd
- **New Name:** Hirect Limited
- **Scrip Code:** 504036
- **Scrip ID for BOLT Plus:** HIRECT (No change)
- **Abbreviated Name on BOLT Plus:** HIRECT (No change)
- **Effective Date:** August 18, 2026

## Regulatory Changes

There are no broader regulatory changes introduced by this circular. This is a standard corporate action notification specific to Hind Rectifiers Ltd.

## Compliance Requirements

- **Trading Members:** Update back-office systems and client-facing terminals to display the new name **Hirect Limited** starting August 18, 2026.
- **Market Participants:** Note that order placement and tracking will continue to use the existing Scrip Code (504036) and Scrip ID (HIRECT).

## Important Dates

- **Notice Date:** August 12, 2026
- **Effective Date:** August 18, 2026

## Impact Assessment

- **Operational Impact:** Low. Systems need to be updated with the new name, but since key identifiers like Scrip Code and Scrip ID are unchanged, no significant operational disruptions are expected.
- **Market Impact:** Low. This is a name change for identity purposes and does not affect the trading segment, liquidity, or fundamentals of the security.
