## Summary

NSE Clearing Limited is implementing OTP-based Two Factor Authentication (2FA) for user logins (Admin and Sub users) in NCMS-CD to enhance security. A new EXE version 4.2.5 will be available from September 12, 2026, and 2FA will be mandatory effective September 15, 2026.

## Key Points

- Implementation of OTP-based Two Factor Authentication (2FA) for NCMS-CD user logins.
- New EXE version 4.2.5 released for download from member Extranet/portal under `cdsftp/cdscommon/NCMSSetup_425`.
- First-time login requires mobile number and email ID registration followed by OTP verification.
- User ID will be disabled after 4 consecutive invalid OTP attempts, requiring assistance from NSE Clearing Ltd.

## Regulatory Changes

- Enhancement of security protocols for clearing and settlement user access via NCMS-CD.

## Compliance Requirements

- Members must download and upgrade to NCMS version 4.2.5.
- Users must register their mobile number and email ID during the initial login to complete 2FA setup.

## Important Dates

- **12-Sep-2026:** New EXE version 4.2.5 made available.
- **15-Sep-2026:** OTP-based 2FA implemented and enforced for NCMS-CD logins.

## Impact Assessment

- Improves operational security for currency derivatives clearing member logins but requires immediate client software upgrades and user credential registrations.
