## Summary

National Stock Exchange of India Limited (NSE) announced a mock trading session in the Commodity Derivatives segment scheduled for Saturday, September 19, 2026. The session aims to test system readiness, connectivity parameters, and software versions for members.

## Key Points

- Mock Date: September 19, 2026.
- Trading Session from DR Site with Normal Market open at 11:15 hrs and close at 12:30 hrs.
- Position Limit/Collateral value Set up cut off time and Trade Modification end time set at 12:40 hrs.
- Live Re-login timings: start time 14:00 hrs, close time 14:30 hrs.
- NEAT Version: 1.5.5.
- All outstanding orders will be cleared before each session; NNF users must manually clear orders.
- Trades during mock sessions will not result in any fund pay-in or pay-out.
- NOTIS application will not be available during the mock session.

## Regulatory Changes

None.

## Compliance Requirements

Members should participate using all trading software and re-login into the live environment to ensure smooth connectivity for Monday, September 21, 2026. Only valid and compliant UCC/PAN uploaded and approved before cutoff will be allowed.

## Important Dates

- Mock Date: September 19, 2026
- Live Re-connectivity / Market resumption: September 21, 2026

## Impact Assessment

Operational check for members participating in the Commodity Derivatives segment to ensure seamless connectivity and readiness for live trading.
