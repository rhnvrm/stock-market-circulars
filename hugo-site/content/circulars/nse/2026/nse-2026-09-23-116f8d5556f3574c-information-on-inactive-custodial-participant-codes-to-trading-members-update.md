## Summary

NSE Clearing Limited has issued an update regarding the submission of Inactive Custodial Participant (CP) codes. Based on feedback from custodians and members, the file format has been revised to include an additional column for 'Only Sell Allowed' to allow clients to execute sell transactions even if their CP code is inactive for other activities. The facility will be available starting September 28, 2026.

## Key Points

- Introduction of an additional column 'Only Sell Allowed' ('Y' / blank) in the Inactive CP code file format.
- Facility available starting from September 28, 2026.
- Uploads can be made through the N-MASS application between 09:00 AM to 07:00 PM on working days.
- File nomenclature remains 'CM_InactiveCP_DDMMYYYY_nn.csv'.
- All inactive CP codes must be provided in a single file; entire file needs to be uploaded for any modifications.

## Regulatory Changes

- Revision of the Inactive CP code file format to support the 'Only Sell Allowed' flag.

## Compliance Requirements

- Custodians must assign '-INACTIVE CP' for 'FILE UPLOAD' and 'FILE DOWNLOAD' service through ROLE MANAGEMENT with 'Write' access in N-MASS.
- Valid CP codes must be in UPPER CASE without extra spaces or junk characters.
- Entire file with all records needs to be uploaded for any addition, deletion, or modification.

## Important Dates

- Effective Date: September 28, 2026
- Circular Date: September 23, 2026

## Impact Assessment

- Enhances operational flexibility for clients associated with inactive CP codes by permitting sell transactions when specified.
