## Summary

National Stock Exchange of India Limited issued a circular regarding Standardisation Testing and Quality Certification (STQC) and other compliance requirements for vendors as per SEBI's Cyber Security and Cyber Resilience Framework (CSCRF).

## Key Points

- Mandates STQC certification for software services and products (CTCL, IBT, STWT, API, BackOffice, etc.) provided by empanelled and prospective vendors.
- Covers application security testing including Dynamic Application Security Testing (DAST) and Static Application Security Testing (SAST).
- Covers functional audits across login, user management, input validation, navigation, CRUD operations, and business logic validation.
- Provisional empanelment is granted based on STQC labs’ acknowledgement; final empanelment requires the certificate from the STQC regional centre.

## Regulatory Changes

Enforces SEBI's Cyber Security and Cyber Resilience Framework (CSCRF) requirements for software services and products provided to regulated entities.

## Compliance Requirements

Vendors must perform application security testing and functional audits through an STQC auditor and submit necessary certifications or compensatory control letters where closure is pending.

## Important Dates

- Date of Circular: September 02, 2026

## Impact Assessment

Vendors providing software solutions to stock exchange members must comply with rigorous STQC testing standards, impacting vendor onboarding and product registration timelines.
