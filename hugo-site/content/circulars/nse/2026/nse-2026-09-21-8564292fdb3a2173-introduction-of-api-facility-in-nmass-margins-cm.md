## Summary

NSE Clearing Limited has introduced an API facility in NMASS-Margins-CM, detailing technical integration guidelines for secure message exchange using AES and RSA cryptographic algorithms.

## Key Points

- Integration covers AES-256-CBC with PKCS5 Padding and RSA algorithms for secure communication.
- Mandates specific key and IV requirements (256-bit secret key, 128-bit IV for AES).
- Provides step-by-step encryption and decryption flows for members.

## Regulatory Changes

- Implementation of standardized encryption and decryption protocols for API-based margin systems.

## Compliance Requirements

- Clearing members must adopt the specified AES and RSA encryption standards and key requirements to interact with the NMASS-Margins-CM API facility.

## Important Dates

- Effective immediately as per circular guidelines.

## Impact Assessment

- Enhances security and enables automated integration for clearing members using the NMASS-Margins-CM platform.
