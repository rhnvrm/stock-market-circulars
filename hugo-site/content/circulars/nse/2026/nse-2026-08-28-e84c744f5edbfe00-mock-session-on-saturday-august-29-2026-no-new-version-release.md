## Summary

National Stock Exchange of India Limited has announced a mock trading session in the Commodity Derivatives segment on Saturday, August 29, 2026. The session is designed to test connectivity and trading operations from the primary site without any financial obligations or new version releases.

## Key Points

- Mock Date: August 29, 2026.
- Trading Session-1 from Primary Site: Normal Market open at 13:00 Hrs, close at 15:45 Hrs.
- Position Limit/Collateral value Set up cut off time: 15:55 Hrs.
- Trade Modification end time: 15:55 Hrs.
- Live Re-login start time: 18:30 Hrs, close time: 19:00 Hrs.
- NEAT Version: 1.5.5.
- All outstanding orders will be cleared before each session; members using NNF software must manually clear orders.
- Trades during mock sessions will not result in any fund pay-in or pay-out.
- NOTIS application will not be accessible during the mock session.

## Regulatory Changes

None. Compliance with SEBI circular SEBI/HO/MRD1/DSAP/CIR/P/2020/234 and existing regulatory requirements applies.

## Compliance Requirements

- Only valid and compliant UCC/PAN uploaded and approved before the cutoff will be allowed.
- Members should participate using all trading software and re-login into the live environment to ensure smooth connectivity for Monday, August 31, 2026.
- Set appropriate branch and user limits from the Corporate Manager Terminal before placing orders.

## Important Dates

- Mock Date: August 29, 2026
- Live Re-login: August 29, 2026 (18:30 Hrs to 19:00 Hrs)
- Live Environment Readiness: August 31, 2026

## Impact Assessment

Operational drill for trading members to verify connectivity, box ID setup, and NNF/NEAT configurations in the Commodity Derivatives segment with zero financial risk.
