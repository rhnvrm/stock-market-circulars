## Summary

The National Stock Exchange of India (NSE) is conducting a mock trading session in the Futures & Options (F&O) segment on Sunday, August 02, 2026. The primary purpose of this session is to test changes in trading modalities in the Equity Derivatives segment resulting from the introduction of the Call Auction Session (CAS) in the Equity Cash Market. No new software version is being released; members should use existing compatible NEATPlus versions and prepare for upcoming market data broadcast changes.

## Key Points

- **Mock Trading Schedule**: The mock session is scheduled for Sunday, August 02, 2026. Normal market opens at 10:15 a.m. and closes at 11:55 a.m. Re-login sessions will run from 14:00 p.m. to 14:30 p.m.
- **No New Version**: No new NEATPlus software is released. Members can continue using compatible versions 7.8.8 and 7.8.9.
- **Price Band Reference**: Reference prices for stock futures contracts under CAS will be determined based on the Volume Weighted Average Price (VWAP) of trades executed between 10:55 a.m. and 11:10 a.m.
- **Discontinuation of Broadcast Parameters**: Existing market data broadcast parameters for NNF users will be discontinued from September 05, 2026. Members must plan to migrate to the new parameters.
- **No Financial Obligation**: Trades executed during the mock session will not result in any financial pay-in or pay-out.

## Regulatory Changes

- **CAS Alignment**: Integration and testing of Equity Derivatives trading modalities aligned with Call Auction Sessions in the Cash Market.
- **Testing Compliance**: System testing conforms to Exchange circular NSE/MSD/46441 and SEBI circular SEBI/HO/MRD1/DSAP/CIR/P/2020/234.

## Compliance Requirements

- **Software Upgrades**: Ensure systems run compatible NEATPlus versions 7.8.8 or 7.8.9. Note that version 7.8.8 will be discontinued on September 05, 2026.
- **NNF Broadcast Migration**: Members using direct connections via NNF must migrate to the new market data broadcast parameters prior to September 05, 2026.
- **Order Purge**: Outstanding orders will be cleared before each session. Members using NNF software must manually clear orders in their systems.
- **UCC Validation**: Ensure only valid and compliant UCC/PAN details are used (validation will be skipped during contingency time).

## Important Dates

- **Mock Trading Session**: Sunday, August 02, 2026
- **Discontinuation of NEATPlus 7.8.8 (Mock)**: September 05, 2026
- **Discontinuation of Existing NNF Broadcast Parameters**: September 05, 2026

## Impact Assessment

- **Operational Impact**: Medium. Trading members must participate in mock sessions to verify their systems can handle the new CAS-aligned price band mechanism. Failure to migrate to new broadcast parameters by September 05, 2026, will disrupt market data feeds for NNF users.
- **System Impact**: Low. No new software version deployment is required for this specific session, but coordination for future version upgrades (NEATPlus 7.8.9 migration) and parameter updates is necessary.
