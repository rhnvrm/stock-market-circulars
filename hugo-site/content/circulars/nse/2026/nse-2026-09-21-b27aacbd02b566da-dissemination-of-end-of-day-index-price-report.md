## Summary

National Stock Exchange of India Limited (NSE) has issued a circular regarding the dissemination of the End of Day Index Price Report, which will be effective from October 12, 2026. Members are advised to review the file nomenclature, extranet location, and file format structures to make necessary system-level changes.

## Key Points

- Effective Date: October 12, 2026.
- Report Type: End of Day Index Price Report.
- Extranet Location: `/cmftp/common/bhavcopy`.
- File Nomenclature: `F CM_IDDDMMYYYY.DAT`.

## Regulatory Changes

No regulatory changes; this is an operational update regarding data dissemination formats for exchange members.

## Compliance Requirements

Trading members should incorporate the required system-level changes for file nomenclature and report structures as applicable.

## Important Dates

- Circular Date: September 21, 2026
- Effective Date: October 12, 2026

## Impact Assessment

Minimal operational impact on members who utilize end-of-day index price reports for back-office or automated processing systems.
