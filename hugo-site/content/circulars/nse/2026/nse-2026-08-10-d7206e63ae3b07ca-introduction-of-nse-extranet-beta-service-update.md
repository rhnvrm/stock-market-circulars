## Summary

The National Stock Exchange of India Limited (NSE) has released an update regarding the "NSE Extranet Beta" service, in continuation to its previous Circular Ref No. NSE/MSD/73589 dated April 02, 2026. This release introduces new capabilities to the platform to improve the user experience for trading members, specifically enhancing the file download functions and bringing the NSEIL Dashboard onto the Extranet Beta platform.

## Key Points

- **New File Download Features:**
  - **Date Range Selection:** Users can select a specific range of dates to filter files.
  - **Multi-File and Bulk Download:** Members can download individual files (one or more) or download all displayed files at once.
  - **In-Folder Search:** A search tool allows users to locate specific files within a directory.
- **NSEIL Dashboard Integration:**
  - Integrated onto the Extranet Beta platform, enabling members to track report delivery and status across various segments.
  - Provides uninterrupted status visibility and direct downloads of multiple reports.
  - Reports are available in parallel on both legacy Extranet and Extranet Beta, with paths remaining unchanged. Reports are published on the beta platform approximately 5 minutes after their release on the existing Extranet.
  - Features filtering options by market segment and file availability status (e.g., Completed or Scheduled).
- **Access Requirements:** Accessible via the integrated Member Portal website (`https://inspection.nseindia.com/MemberPortal/`). Best viewed in Google Chrome or Internet Explorer 11.0+. Authentication requires User ID, Member Code, Password, Captcha, and OTP verification.

## Regulatory Changes

- No regulatory frameworks or rules have been modified. This update is purely technical and operational, affecting reporting utility tools for trading members.

## Compliance Requirements

- **Access Verification:** Member Admin users and trading members should test and adapt to these new features on the NSE Extranet Beta interface.
- **Authentication Readiness:** Ensure users have active credentials and OTP configurations to log in to the integrated Member Portal.
- **Workflow Adaptation:** Support teams should note the 5-minute replication delay between the existing Extranet and the Extranet Beta platform.

## Important Dates

- **Circular Date:** August 10, 2026
- **Previous Reference Date:** April 02, 2026
- **Effective Date:** Immediate

## Impact Assessment

- **Operational Impact:** Low/Medium. Enhances the efficiency and speed with which compliance and back-office teams can query, find, and bulk-download necessary trade-related reports.
- **Market Impact:** Low. There is no disruption to trading, clearing, or settlement systems.
- **System Impact:** Minimal. Download paths remain completely identical to the existing Extranet, avoiding any urgent automation script modifications for trading members.
