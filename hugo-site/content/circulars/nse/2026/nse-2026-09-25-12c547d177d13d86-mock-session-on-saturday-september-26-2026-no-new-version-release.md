## Summary

National Stock Exchange of India Limited is conducting a mock trading session in the Commodity Derivatives segment on Saturday, September 26, 2026. No new version release is applicable for this session.

## Key Points

- Mock Date: September 26, 2026.
- Trading Session from Primary Site: Normal Market open at 11:00 hours, close at 12:30 hours. Position Limit/Collateral value set up cut-off time and Trade Modification end time is 12:40 hours.
- Live Re-login start time: 16:00 hours; Live Re-login close time: 16:30 hours.
- NEAT Version: 1.5.5.
- Order Purge: All outstanding orders will be cleared before each session. Members using NNF software must manually clear orders.
- No Financial Obligation: Trades during mock sessions will not result in any fund pay-in or pay-out.
- UCC/PAN Validation: Only valid and compliant UCC/PAN uploaded and approved before cutoff will be allowed.

## Regulatory Changes

None. Routine operational mock session.

## Compliance Requirements

Members should participate using all trading software and re-login into the live environment to ensure smooth connectivity for Monday, September 28, 2026.

## Important Dates

- Mock Session Date: September 26, 2026
- Live Re-login: September 26, 2026 (16:00 to 16:30 Hrs)

## Impact Assessment

Minimal operational impact. Ensures trading systems and connectivity are functioning properly for the upcoming trading week.
