## Summary

National Stock Exchange (NSE) has released enhancements and the Technical Design Document (TDD) version 2.3 for the UCI-ONLINE (Unique Client Identifier) external interface. This document outlines messaging protocols, authorization mechanisms, API user registration procedures, and technical specifications for integration.

## Key Points

- Technical Design Document Version 2.3 released for UCI External Interface.
- Covers One-Time API User Registration via UAT portal (https://uat.connect2nsccl.com/api-reg/welcome).
- Details core API endpoints including Authentication API, Upload/Process Client API, and Get PAN Status API.
- Establishes request/response payload formats, thresholds, and expected response codes.

## Regulatory Changes

- Updated technical standards and interface protocols for Unique Client Identifier (UCI) submissions and verification.

## Compliance Requirements

- Trading members and participants integrating with UCI-ONLINE must update their systems according to the TDD v2.3 specifications, complete one-time API user registration, and implement authentication and processing endpoints.

## Important Dates

- Effective Date: October 19, 2026 (as per Version 2.3 release date).

## Impact Assessment

- Streamlines client identification data transmission and verification processes for trading members interfacing with NSE/NCCL systems.
