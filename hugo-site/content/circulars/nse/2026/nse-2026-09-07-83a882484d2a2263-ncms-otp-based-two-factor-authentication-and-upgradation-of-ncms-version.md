## Summary

NSE Clearing Limited has announced the implementation of OTP-based Two Factor Authentication (2FA) for user logins (both admin and sub-users) in the NCMS-CO platform to enhance security measures. Additionally, a new EXE version 4.2.5 is being released for download.

## Key Points

- OTP-based 2FA is being introduced for user login in NCMS-CO (Admin and Sub users).
- A new EXE version 4.2.5 will be available from September 12, 2026.
- 2FA will be implemented effectively from September 15, 2026.
- First-time login registration requires valid mobile number and email ID for receiving OTPs.
- Entering 4 invalid OTPs will disable the user ID, requiring contact with NSE Clearing Ltd.

## Regulatory Changes

Implementation of mandatory Two Factor Authentication (2FA) for commodity derivatives segment clearing and risk management systems (NCMS-CO).

## Compliance Requirements

Members must upgrade to NCMS version 4.2.5 and complete the registration of valid mobile numbers and email IDs upon first login to comply with the new 2FA requirements.

## Important Dates

- New EXE Version Release Date: September 12, 2026
- 2FA Implementation Date: September 15, 2026

## Impact Assessment

All members operating in the commodity derivatives segment must upgrade their software and ensure users complete the OTP registration process to avoid login disruptions or user ID disablement.
