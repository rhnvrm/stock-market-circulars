## Summary

Metropolitan Stock Exchange of India Ltd. (MSEI) has released Version 25.0.0.4 of the Trading Market Data API for the Equity Spot segment, dated October 21, 2026. This version update includes updates to field descriptions and the addition of new broadcast message structures.

## Key Points

- **Version:** 25.0.0.4
- **Segment:** Equity Spot Trading Market Data API
- **Release Date:** 21/10/2026
- **Field Updates:** Updated descriptions for 'Indicative Flag' and 'Indicative Close Price' fields in the Market Picture message.
- **New Message Added:** Message 31800 "Final VWAP & Reference Price" added along with its nested message structures and broadcast formats.

## Regulatory Changes

- N/A (Technical API specification update)

## Compliance Requirements

- Trading members and software vendors utilizing MSEI Equity Market Data API should review the updated specification version 25.0.0.4 and incorporate necessary changes for handling message 31800 and updated field descriptions.

## Important Dates

- **Release Date:** 21/10/2026

## Impact Assessment

- Minimal impact on standard trading operations; relevant primarily to algorithmic traders, market data vendors, and back-end integration developers consuming MSEI equity feed.
